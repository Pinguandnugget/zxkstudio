# Leviathan Abisal — alpha 0.1
Subproyecto independiente dentro de zxkstudio. Java 21, Fabric 1.21.1, GeckoLib 4.7.6.
La rama main y el build original no se modifican. Compilar desde esta carpeta con Gradle 8.10.2: gradle build.
IMPORTANTE: faltan los seis recursos exportados de Blockbench (Boss V39 y Full V36). Extraer el ZIP Leviathan_Assets_zxkstudio.zip dentro de esta carpeta antes de compilar o instalar.
Config: config/leviathan_abisal.json, maxHealth 300000. Reiniciar para aplicar.
Comando previsto: /summon leviathan_abisal:leviathan ~ ~ ~.
Estado experimental: barra y salud independiente persistente, fases, selección de animaciones y pulsos de mordida; no captura física ni garantía de tótem. Los demás ataques son solo animaciones. Full aún no está registrada. Pendientes hitboxes, daño sincronizado, efectos, muerte/loot, pruebas Arclight y compilación. No instalar en producción.
